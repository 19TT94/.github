# Default community health files

Account-wide defaults for [19TT94](https://github.com/19TT94) repositories. Repos without their own copies inherit these issue templates.

## Agent-accessible issues

Use labels to mark whether an AI agent may work an issue:

| Label | Meaning |
| --- | --- |
| `agent` | Suitable for an agent to implement end-to-end |
| `no-agent` | Human-only; agents must not start without explicit approval |

**Unlabeled** issues: agents should ask before starting.

Create both labels in each repository (they are not created automatically). Issue templates include an **Agent accessible** checklist so authors pick one when filing.
